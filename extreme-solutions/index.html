Tecnología de producto

Herramientas conectadas de la interfaz al lanzamiento.

Elegimos cada capa para que la solución sea clara para quien la usa y sólida para quien la opera, mantiene y publica.

Frontend móvil

Android nativo

Kotlin, Java, Android SDK y Gradle para interfaces, captura en cámara y galería, firmas, permisos, archivos, tareas en segundo plano con WorkManager y operación sin depender de una computadora.

Frontend web

Interfaces de operación

React, Vite y Tailwind CSS para paneles web ágiles, consistentes y orientados a ventas, inventario, recetas, cortes y reportes.

Backend y datos

Información que permanece útil

Base44, almacenamiento local con SharedPreferences, Google Sheets y Google Photos Library API con OAuth (Google Identity Services) para conservar, respaldar, organizar y consultar información.

Documentos y medios

Evidencia lista para entregar

PDF nativo, Excel, imágenes, anotaciones, firmas y acceso controlado a archivos para convertir el trabajo diario en entregables claros.

Calidad y despliegue

Del repositorio al usuario

GitHub, Vercel, Android Studio, pruebas en dispositivo, Google Play Console con pruebas cerradas y Google Play Billing para construir, validar, publicar, monetizar y mejorar cada producto.

IA y seguridad

Agentes LLM protegidos

Python, MCP (Model Context Protocol) e integración de LLM con el patrón Dual LLM: memoria simbólica, monitor de referencia y herramientas fijadas con SHA-256 contra la inyección de prompts y el envenenamiento de herramientas.

Método

Del problema operativo a una herramienta usable.

Nuestro proceso combina criterio técnico con sensibilidad de usuario: entendemos la tarea, simplificamos el flujo y hacemos que cada solución sea clara, útil y presentable.

01

Detectar pérdida de tiempo

Ubicamos dónde un proceso se vuelve lento, manual o difícil de repetir.

02

Diseñar el flujo mínimo

Ordenamos capturas, pasos y botones para que el usuario avance sin pensar de más.

03

Validar en teléfono

Probamos teclado, cámara, firmas, exportación, orientación y casos reales de uso.

04

Publicar y presentar

Preparamos builds, políticas, recursos visuales y material comercial para mostrar el producto.

MCP Dual LLM Guard

Desarrollamos un middleware en Python que neutraliza por diseño la inyección indirecta de prompts y el envenenamiento de herramientas MCP: un LLM privilegiado planifica solo con punteros, un LLM en cuarentena lee los datos sin acceso a herramientas y un monitor de referencia decide qué datos llegan a cada herramienta.
